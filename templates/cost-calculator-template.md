# Azure Cost Calculator Template — Excel Structure Guide

This document defines the structure for Azure cost calculator workbooks generated by the skill using Excel MCP.

---

## Workbook Layout

### Sheet 1: Summary

| Row | A | B | C | D |
|-----|---|---|---|---|
| 1 | **Azure Cost Calculator** | | | |
| 2 | Generated: [date] | Region: =Assumptions!Region | Strategy: =Assumptions!Strategy | Azure Split: =Assumptions!Azure_Split |
| 4 | **Category** | **Monthly** | **Annual** | **% of Total** |
| 5 | Compute (net of AHB) | =Compute!Total | =B5*12 | =B5/$B$11 |
| 6 | Storage | =Storage!Total | =B6*12 | =B6/$B$11 |
| 7 | Networking | =Network!Total | =B7*12 | =B7/$B$11 |
| 8 | PaaS & Data | =PaaS!Total | =B8*12 | =B8/$B$11 |
| 9 | Hybrid | =Hybrid!Total | =B9*12 | =B9/$B$11 |
| 10 | Support | =support_cost | =B10*12 | =B10/$B$11 |
| 11 | **TOTAL** | =SUM(B5:B10) | =SUM(C5:C10) | 100% |
| 13 | *AHB Savings (memo)* | =AHB!Total | =B13*12 | Licensing avoided |

**Charts**: Pie chart (cost by category), Bar chart (monthly vs. annual)

---

### Sheet 2: Compute

| Column | Content | Example |
|--------|---------|---------|
| A | Service | VM, AKS, App Service |
| B | SKU/Tier | D4s_v5, P2v3 |
| C | Quantity | 3 |
| D | Hours/Month | 730 (24x7) or custom |
| E | Base Price ($/hr) | License-excluded (Linux/base) price from `mcp_azure_mcp_pricing` |
| F | OS / License | Windows Server, SQL Server Ent/Std, Linux/None |
| G | License Uplift ($/hr) | Windows/SQL license portion from `mcp_azure_mcp_pricing` |
| H | AHB Applied? | Yes/No — only if eligible (see AHB sheet) |
| I | Reserved? | Yes/No |
| J | Reserved Discount % | =IF(I="Yes", 40%, 0%) |
| K | Effective License $/hr | =IF(H="Yes", 0, G) |
| L | Monthly Cost | =C*D*(E+K)*(1-J) |

> **AHB rule**: Azure Hybrid Benefit removes the Windows/SQL **license uplift** (column G), not the base compute (column E). When `AHB Applied? = Yes`, the effective license cost becomes 0. AHB and Reserved Instances **stack** — apply both for maximum savings.

### Sheet 6: Assumptions

| Parameter | Value | Notes |
|-----------|-------|-------|
| Region | East US 2 | **Required** — drives all region-specific unit pricing |
| Migration Strategy (6R) | Rehost | **Required** — Rehost/Replatform/Refactor/Rearchitect/Rebuild/Replace |
| Hybrid Split (% Azure) | 100% | **Required** — % of workload in Azure vs on-prem (e.g., 70% = 70% Azure / 30% on-prem) |
| AHB — Windows Server | No | Apply Azure Hybrid Benefit for Windows Server (requires Software Assurance) |
| AHB — SQL Server | No | Apply Azure Hybrid Benefit for SQL Server (requires Software Assurance) |
| Currency | USD | |
| Pricing Model | Pay-as-you-go | vs. Reserved |
| Reserved Term | 1 year | 1yr or 3yr |
| Growth Rate | 10% | Annual data/compute growth |
| Support Plan | Standard | Basic/Standard/Professional |
| Hours/Month | 730 | 24x7 = 730, business hrs = 260 |

> **Constitution Domain 6 requirement**: Region, Migration Strategy (6R), and Hybrid Split are mandatory editable input cells. All downstream sheets reference these cells (named ranges `Region`, `Strategy`, `Azure_Split`) so changing an assumption recalculates the entire workbook.

---

### Sheet 7: Strategy (6R)

Captures how the selected migration strategy changes the target services and cost model. The selected strategy (from Assumptions) drives which services appear on the Compute/PaaS sheets and applies a cost multiplier.

| Column | Content | Example |
|--------|---------|---------|
| A | 6R Strategy | =Assumptions!Strategy |
| B | Cost Model | IaaS VM / PaaS / Serverless / Cloud-native / Greenfield / SaaS |
| C | Primary Azure Targets | VMs / App Service / Functions / AKS / Cosmos / M365 |
| D | Strategy Multiplier | =VLOOKUP(A, strategy_table, 2) |
| E | One-Time Migration Cost | Assessment + cutover effort |

**Strategy reference table** (drives multiplier & targets):

| Strategy | Cost Model | Primary Targets | Typical Run-Cost vs Rehost |
|----------|-----------|-----------------|----------------------------|
| Rehost | IaaS VM + managed disks | VMs, Managed Disks | 1.00 (baseline) |
| Replatform | PaaS, minimal change | App Service, ACI, SQL MI | 0.85 |
| Refactor | Serverless / containers | Functions, Container Apps | 0.65 |
| Rearchitect | Cloud-native | AKS, microservices, Cosmos | 0.70 |
| Rebuild | Greenfield Azure-native | Azure-native PaaS | 0.60 |
| Replace | SaaS substitution | M365, Dynamics, Power Platform | per-seat license |

---

### Sheet 8: Hybrid

Captures hybrid (split on-prem + Azure) cost components. Only populated when Hybrid Split < 100% Azure.

| Column | Content | Example |
|--------|---------|---------|
| A | Hybrid Component | Azure Arc, ExpressRoute, VPN Gateway, Azure Stack HCI, AVS |
| B | Unit/Tier | Arc per-server, ER circuit 1 Gbps, AVS node AV36 |
| C | Quantity | 10 servers / 1 circuit / 3 nodes |
| D | Unit Cost ($/month) | From `mcp_azure_mcp_pricing` |
| E | Monthly Cost | =C*D |
| F | Allocation | =Assumptions!Azure_Split applied where shared |

**Hybrid cost components to include:**
- **Azure Arc** — per-server management & Arc-enabled service licensing
- **Connectivity** — ExpressRoute circuit or VPN Gateway (fixed + egress)
- **On-prem extension** — Azure Stack HCI nodes or Azure VMware Solution (AVS) nodes
- **Split allocation** — Total = Azure workloads × Azure_Split + on-prem workloads × (1 − Azure_Split)

---

### Sheet 9: AHB (Azure Hybrid Benefit)

Quantifies licensing savings from applying existing Windows Server / SQL Server licenses (with Software Assurance) to Azure. AHB removes the license uplift; it stacks with Reserved Instances. Each line ties back to a Compute row.

| Column | Content | Example |
|--------|---------|---------|
| A | Product | Windows Server, SQL Server Ent, SQL Server Std, RHEL/SUSE |
| B | Eligible? | Yes/No — requires Software Assurance or qualifying subscription |
| C | Licenses Owned | Count of cores/core-packs available |
| D | Coverage Rule | WS: 8-core pack→up to 8 vCPU, 16-core min/server; SQL Ent: up to 4 vCore/license; SQL Std: 1:1 |
| E | Covered vCPU/vCore | =MIN(license-derived capacity, deployed vCPU) |
| F | License Uplift Avoided ($/mo) | =covered_units × uplift_rate × 730 |
| G | AHB Applied? | =Assumptions!AHB_Windows / AHB_SQL toggle |
| H | Net Savings ($/mo) | =IF(B="Yes" AND G="Yes", F, 0) |

**AHB eligibility & coverage rules** (must be honored — do not overstate savings):

| Product | Benefit | Coverage Rule |
|---------|---------|---------------|
| Windows Server | Reuse SA/CSP licenses on Azure VMs | 8-core pack = 1 VM up to 8 vCPUs; 16-core minimum per server |
| SQL Server Enterprise | Azure VM, SQL MI, SQL DB | Up to 4 vCores per core license |
| SQL Server Standard | Azure VM, SQL MI, SQL DB | 1 vCore per core license (1:1) |
| Azure Arc | Extend AHB to on-prem / multi-cloud | SQL Server & Windows Server outside Azure |
| RHEL / SUSE | Bring existing subscriptions (BYOS) | Convert PAYG → BYOS |
| Azure Stack HCI / AKS | Windows Server licenses for AKS, AVD | Software Assurance required; per-node |

> **Dual-use rights**: During migration (up to 180 days) the same license may run both on-prem and in Azure — do not double-count this as extra cost.
>
> **Honesty rule**: Only mark `Eligible? = Yes` when Software Assurance (or a qualifying subscription) actually exists. Cap covered vCPU/vCore at owned-license capacity. AHB reduces the **license** portion only — never the base compute, storage, or networking.

## Formatting Standards

- **Headers**: Bold, dark blue fill, white text
- **Currency cells**: `$#,##0.00` format
- **Percentage cells**: `0%` format
- **Totals row**: Bold with top border
- **Named ranges**: Use for cross-sheet references (e.g., `Compute_Total`, `Region`, `Strategy`, `Azure_Split`, `AHB_Windows`, `AHB_SQL`)
- **Conditional formatting**: Red for costs > threshold, green for savings

## Formula Patterns

```excel
# Growth projection (n months)
=monthly_total * (1 + growth_rate/12) ^ n

# Reserved instance savings
=payg_cost * (1 - reserved_discount)

# 3-year TCO
=SUM(annual_costs) * 3 + migration_cost

# Break-even month for reserved vs. PAYG
=reserved_upfront / (payg_monthly - reserved_monthly)

# Region-driven unit price lookup
=VLOOKUP(Region, region_pricing_table, price_col, FALSE)

# 6R strategy cost adjustment
=base_cost * VLOOKUP(Strategy, strategy_table, multiplier_col, FALSE)

# Hybrid split allocation
=azure_cost * Azure_Split + onprem_cost * (1 - Azure_Split)

# Azure Hybrid Benefit — effective license cost (uplift removed when applied)
=IF(AHB_Applied, 0, license_uplift_per_hr)

# AHB net savings (license uplift avoided, capped at owned-license capacity)
=IF(AND(ahb_eligible, ahb_applied), covered_units * uplift_rate * 730, 0)

# AHB stacks with Reserved Instances
=qty * hours * (base_price + IF(AHB_Applied, 0, license_uplift)) * (1 - reserved_discount)
```
